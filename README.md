# douze
Stupidly simple, blazing fast static site generator

# installation

```
dotnet tool install -g douze --prerelease
```

# usage

Usage: douze [options]

Options:
-o|--output     Output path
-s|--source     Source path
-d|--data       Data folder. Can be specified multiple times.
-c|--content    Content folder. Can be specified multiple times.
-i|--includes   Includes folder. Can be specified multiple times.
